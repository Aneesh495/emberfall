# Depth-tested additive effects

The game and play world turn latch, mirror, checkpoint, fall and completion events into short-lived emitters. A CPU pool holds at most 32 emitters. It ages them at 60 Hz and expires them after 1.5 s. If the pool fills, it drops the oldest emitter. Emitter positions, seed and age are presentation state. The game does not add them to saves, snapshots or replay hashes. [Emitter pool](../src/effects.cpp), [game event path](../src/native/game_main.cpp), [editor play loop](../src/native/editor_main.cpp)

A burst generates 24 billboards in the vertex shader. The shader hashes the emitter seed and instance index to choose a ballistic trajectory and lifetime. There is no per-particle CPU update or particle upload. A ground decal uses a procedural expanding ring in the XZ plane. It is placed slightly above a known horizontal beacon or recovery surface. It does not project onto arbitrary meshes. [Vertex motion](../shaders/effects.vert), [coverage shader](../shaders/effects.frag)

The effects pass loads the opaque depth in a read-only layout and blends linear radiance additively into a cleared RGBA16F layer. The display shader combines this layer with the resolved scene before exposure and sRGB conversion. The effect color stays out of temporal history. This path supports emissive effects without back-to-front sorting. General alpha-blended materials, particles that cast shadows, and translucent occlusion remain outside the current effect path. [Frame recording](../src/gpu/frame.cpp), [display shader](../shaders/tonemap.frag), [Vulkan attachment store operations](https://docs.vulkan.org/refpages/latest/refpages/source/VkAttachmentStoreOp.html)

The test compares a reference framebuffer with a visible burst, a ground ring and a burst fully inside an opaque block. The independent verifier repeats those comparisons from the saved pixel bytes. The stress scene draws both effects every frame and retains a separate timestamp boundary for the pass. [GPU fixture](../tests/gpu_effects.cpp), [evidence verifier](../scripts/verify_evidence.py)
